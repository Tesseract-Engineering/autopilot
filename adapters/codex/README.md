# Codex adapter (not built in v1)

The core (`core/scripts`, `core/roles`, `core/skills`) is harness-neutral. A Codex
adapter would be generated by `build.sh` the same way `plugins/autopilot/` is.
Until then, Codex users get the **git backstop** (`autopilot install-git --ci`):
the same `.claude/checks.sh` and protected-path verdict, enforced at push and in CI.

## What a Codex adapter needs
| Piece | Claude adapter | Codex equivalent (from Codex docs, 2026-11) |
|---|---|---|
| Manifest | `.claude-plugin/plugin.json` | `.codex-plugin/plugin.json`, with `"hooks": "./hooks/hooks.json"` |
| Roles | `agents/*.md` frontmatter | one TOML file per agent (`name`, `description`, `developer_instructions`, optional `model`, `model_reasoning_effort`) |
| Skill | `skills/*/SKILL.md` | Agent Skills `SKILL.md`, copied unchanged |
| Stop gate | `Stop` exit 2 continues the turn | `Stop` exists. `decision:"block"` or exit 2 **continues** the turn with the reason as a new prompt. Same semantics, so the `stop.sh` shim ports almost unchanged |
| Subagent gate | `SubagentStop` + `agent_type` | `SubagentStop` exists and continues the same way. **Unverified:** whether its input identifies the agent type or carries a transcript path for the slice marker |
| Write rules | `PreToolUse` deny | `PreToolUse` supports `permissionDecision: "deny"` |

## Blockers found in the Codex docs
1. **Hooks need per-user trust.** Hooks that aren't managed must be reviewed with `/hooks`
   before they run, and re-trusted after every change. A freshly installed plugin's
   gate is **off** until each engineer trusts it, which breaks "enforcement by
   default". An org-managed `/etc/codex/hooks.json` avoids this.
2. **No per-agent tool allow-list.** Codex agent TOML can't set `tools`, `sandbox_mode`
   or `approval_policy` per agent; subagents inherit the parent's sandbox. A
   **read-only reviewer can't be enforced** per agent. Workaround: run the reviewer as a
   separate `codex exec` with a read-only sandbox, and pass the diff in.
3. **Agent identity in hook input:** not documented. Without it, SubagentStop can't tell
   implementers from reviewers, and would need the slice marker plus a transcript
   path, which is also not documented.

Next step: verify 2 and 3 against a live Codex build, then add `adapters/codex/` templates
and a `build.sh` target.
